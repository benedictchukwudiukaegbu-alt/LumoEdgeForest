# Lumo Edge Forest Scanner — Dashboard Edition

Owner: Gontse

## Dashboard
- Live-market dashboard for AUDUSD, AUDCAD, EURUSD, GBPUSD, USDJPY and XAUUSD.
- BUY/SELL signal cards.
- Scan Market Now button.
- Signal history.
- EMA 50/200 + RSI 14 + ATR strategy label.

## Important
This project contains the Android UI and scanner framework. The displayed market prices/signals require a live market-data API integration before they can be considered live trading data. It does not connect to or place trades in an Exness account.

Build with Android Studio to create the APK.
